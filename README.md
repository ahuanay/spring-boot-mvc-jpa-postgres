# Spring Boot MVC JPA PostgreSQL (`spring-boot-mvc-jpa-postgres`)

Servicio de gestión de empleados desarrollado con **Spring Boot 3.5.16**, **Spring MVC**, **Spring Data JPA** y **PostgreSQL**.

---

## 🛠️ Tecnologías Principales

* **Java 21**
* **Spring Boot 3.5.16**
* **Spring Data JPA / Hibernate**
* **PostgreSQL** (Flyway para migraciones)
* **Lombok & MapStruct**
* **OpenAPI 3 / Swagger UI**
